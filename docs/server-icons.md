# Ícones de servidores

O cadastro oferece logos de distribuições Linux e ícones genéricos. O botão **Ícone aleatório** escolhe um ícone genérico e permite revisar a escolha antes de cadastrar. O ícone fica salvo no servidor e aparece no inventário e nos detalhes. **Alterar ícone** permite trocar depois.

A escolha é visual; não instala nem detecta um sistema operacional. Cadastros existentes mantêm o ícone de servidor padrão. Não é necessário atualizar o agente.

As formas das logos são fornecidas pelo catálogo local `simple-icons`; os ícones genéricos usam `lucide-react`. O frontend inclui apenas os símbolos utilizados, sem buscar imagens remotas em tempo de execução. Os nomes e símbolos das distribuições identificam seus respectivos projetos.
